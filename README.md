# ST-FMDC

Official repository for:

**ST-FMDC: Foundation Model-Driven Multi-modal Dual-aligned CLIP Framework for Spatial Gene Expression Prediction from H&E Histology Images**

Coming Soon

The code for **ST-FMDC** is currently being organized and will be released after the paper is available online.

ST-FMDC is a foundation model-driven multi-modal framework for predicting spatial gene expression from H&E histology images. It integrates histology foundation features, dual-aligned cross-modal representation learning, spatial context modeling, and imbalance-aware supervision to improve biologically informed spatial transcriptomics prediction.

More details, source code, data processing scripts, pretrained checkpoints, and usage instructions will be updated in this repository.
