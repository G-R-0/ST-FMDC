# ST-FMDC

Official repository for:

**ST-FMDC: A Dual-Aligned CLIP Framework for Spatial Transcriptomics Prediction with Textual Cell-Type Information**

Coming Soon

The code for **ST-FMDC** is currently being organized and will be released after the paper is available online.

ST-FMDC is a multimodal learning framework for predicting spatial gene expression from H&E whole-slide images. It jointly models histological morphology, transcriptomic foundation features, and cell-type semantic text information to improve biological interpretability and robustness.

More details, source code, data processing scripts, pretrained checkpoints, and usage instructions will be updated in this repository.
